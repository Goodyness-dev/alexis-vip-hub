# Alexis &bull; Official VIP Creator Hub

A high-performance, mobile-first VIP link-in-bio website and portfolio hub for Alexis (@MommyAlexiss / @GoonFuelMommy).

## Features

- **Luxury Dark Glassmorphism Aesthetic**: Built with refined rose/gold accents and smooth animations.
- **Direct Telegram & X Integration**: Links directly to `@MommyAlexiss` and `@GoonFuelMommy`.
- **Interactive 18+ Age Gate**: Stored in `localStorage` for returning visitors.
- **Voice Note Teaser**: Realistic audio waveform player simulation.
- **Interactive Preview Lightbox**: Tap-to-expand preview gallery with instant full-set unlock CTAs.
- **Tribute / Worship Modal**: Quick tribute tiers ($25, $50, $100, $250) with direct message routing.
- **One-Click Profile Sharing**: Web Share API integration with automatic fallback to clipboard copy.
- **Zero External Runtime Dependencies**: Can be opened directly in any browser (`index.html`) or served via Node.js.

## Running Locally

The server is currently running at:
```
http://localhost:3000
```

To run manually at any time:
```bash
npm start
# or
node server.js
```
Or simply double-click [`index.html`](./index.html) to view it in any web browser without running a server.

## Deploying to Production

This website is static-ready and can be deployed in seconds with zero build step to:
- **Vercel**: Drag and drop the folder into the Vercel dashboard or run `npx vercel`.
- **Netlify**: Drag and drop the folder into [Netlify Drop](https://app.netlify.com/drop).
- **GitHub Pages**: Push this repository and enable GitHub Pages in repository settings.
- **Cloudflare Pages**: Connect repository or direct upload.
